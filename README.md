# WhatsAppAutoDelete v1.1 (جاهز للبناء عبر GitHub Actions)

## طريقة استخراج ملف APK في دقيقتين (بدون Android Studio)
1. فك ضغط هذا الملف على جهازك.
2. أنشئ مستودعاً جديداً (Repository) على GitHub.
3. ارفع جميع الملفات والمجلدات (تأكد من إظهار الملفات المخفية حتى يُرفع مجلد `.github`).
4. افتح تبويب **Actions** في GitHub، وانتظر انتهاء مهمة **Build Debug APK** (حوالي دقيقتين).
5. اضغط على التشغيل المكتمل ثم حمّل `app-debug` من قسم **Artifacts** وفك ضغطه لتحصل على `app-debug.apk`.
